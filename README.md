# jevplays-games community files

This repository holds the `jevplays-games` organization profile and the default community health files that every repository in the organization inherits. It is stewarded by Complete Tech LLC.

- [Org landing page](profile/README.md): the profile shown on the organization page, with a map of the repositories.
- [Contributing](CONTRIBUTING.md)
- [Security policy](SECURITY.md)
- [Code of conduct](CODE_OF_CONDUCT.md)
- [Support](SUPPORT.md)
- [Issue forms](.github/ISSUE_TEMPLATE): bug report, feature or idea, and the issue chooser configuration.
- [Pull request template](.github/PULL_REQUEST_TEMPLATE.md)

Repositories that ship their own copy of any of these files use theirs instead.
