# jevplay.games community files

This repository holds the jevplay.games organization profile and the default community health files that every repository in the organization inherits. It is stewarded by CompleteTech LLC.

- [Org landing page](profile/README.md): the profile shown on the organization page, with a map of the repositories.
- [Contributing](CONTRIBUTING.md)
- [Security policy](SECURITY.md)
- [Code of conduct](CODE_OF_CONDUCT.md)
- [Support](SUPPORT.md)
- [Issue forms](.github/ISSUE_TEMPLATE): a bug report (game or tool, opponent, what happened, steps to reproduce, version or commit, environment, what you did not check), a feature or idea form (game or tool, problem, proposal, alternatives considered, evidence), and the issue chooser configuration.
- [Pull request template](.github/PULL_REQUEST_TEMPLATE.md): what changed, what you verified, what you did not verify, and the opponent and integration checks.

Repositories that ship their own copy of any of these files use theirs instead.
