# Contributing

Thanks for helping. Keep changes small and say what you verified.

1. Open an issue first for anything beyond a typo or a clear bug, so we can agree on scope.
2. Fork, branch, and open a pull request against the default branch of the repository concerned.
3. Run the tests that repository documents (for the games, `npm test` on Node 22.16 or newer) and paste the result in the PR.
4. Do not commit credentials, `.env` files, player data or production database contents.
5. Keep claims honest. If you did not run something against live Jev, Discord or Cloudflare, say so rather than implying it.

Each repository is separate; check its README and any LICENSE file for its terms. By contributing you agree your work may be used under the terms that repository states.

Questions: see [SUPPORT.md](SUPPORT.md).
